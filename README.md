# Plastic Command (playable build)

**Play in your browser:** https://aducknamedjoe.github.io/plastic-command-play/

A toy-soldier RTS in the style of Army Men (1998) with Company of Heroes-style squads,
cover and suppression, fought across the floors and tabletops of a house. Green vs tan: eliminate every
enemy soldier. Needs a mouse and keyboard.

Four maps: a true-scale kitchen with counters, a dining table and chairs to fight over, plus
the classic kitchen, bedroom and bathroom. The **Field Manual** on the title screen explains
the controls, suppression and morale, cover and height, and every squad.

**Controls:**
- **Left click / drag:** select
- **Right click:** move / attack. Near cover the squad lines up behind it, and the preview shows where.
- **Double right-click / hold Q:** run
- **Ctrl+1–0:** control groups
- **B:** mortar barrage
- **G:** fire at location
- **T:** grenade
- **V:** satchel charge
- **M / E:** mine / barbed wire (engineers)
- **F:** dig in
- **Y / C / K / J:** rally / recon / air strike / paratroopers (Command Squad)
- **R / X:** retreat / stop
- **PgUp / PgDn:** step through the floor, seat and table levels
- **WASD / screen edge:** scroll
- **Wheel / Z:** zoom
- **, and .:** rotate the view

This repository only contains the built game. It includes sprites, sounds and music from the
Army Men (1998) source release, which was published under CC0.
